# Apex Domain-Driven Design Lab Specification

## Architectural Scope
- Application Name: `apex-domaindrivendesign-lab`
- Host Port: `3017`
- Technology Stack: Next.js 16, React 19, TypeScript, Vanilla High-Tech CSS.
- Theme Support: Midnight / Daylight with CSS custom properties.
- Concurrency & Sync: Multi-tab real-time sync via `BroadcastChannel`.
- Export Target: Standalone Docker container and zero-server GitHub/GitLab Pages static export (`out/`).

## Curriculum Levels
1. Level 1: Ubiquitous Language & Linguistic Disambiguation
2. Level 2: Strategic Subdomains (Core vs Supporting vs Generic) & Context Mapping (ACL, Conformist, Shared Kernel, OHS, Published Language)
3. Level 3: Tactical Building Blocks (Value Objects, Entities, Invariants, Aggregate Roots, Domain Events, Event Sourcing, Domain Services)
4. Level 4: Hexagonal Architecture (Ports & Adapters, Zero-Dependency Core)
5. Level 5: Advanced Distributed DDD (Compensating Sagas, Process Managers, CQRS Projections, Master Decision Tree)
